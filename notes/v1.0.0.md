First public release.

Serenade GIF turns a video or an animated GIF into a sprite-sheet texture
and the `llSetTextureAnim` script that plays it back in the Second Life®
virtual world.

- Load MP4, MOV, AVI, MKV, WEBM or animated GIF, or drag one onto the window
- Scrub, trim and crop video before extracting, frame-accurately
- Pick frames by hand, or thin them out to every 2nd / 3rd / 4th
- Drop duplicate frames, and find a seamless loop point automatically
- Export a 256 / 512 / 1024 / 2048 sprite sheet plus ready-to-paste LSL,
  sized to stay inside Mono's 64 KB script memory limit
- Queue several clips and export them all in one pass, with a cycler script
  that swaps between them
- Also exports a real animated .gif, encoded with a bundled FFmpeg using
  two-pass palette generation, with an optional target file size
- Built-in updates: the app tells you when a new version is out and can
  install it itself

Everything runs locally. The only network access is two anonymous reads of
this repository: the release list, and a small `status.json` the author can
use to post a notice or withdraw a build. Neither sends anything about you
or the files you process, and the app works normally if either fails. What
a withdrawal does, and what it cannot do, is set out in the EULA under
UPDATES AND AUTHOR NOTICES.

Free to use, and anything you make with it is yours, including work sold on
the Second Life Marketplace.

## Which file to download

`Serenade.GIF.exe` is the program on its own. Run it and it writes a
`Serenade GIF licences` folder beside itself with all the notices in it,
or into `%LOCALAPPDATA%\Serenade\serenade-gif\licences` if the folder it is sitting in cannot be
written to. The **Licences** button in the toolbar shows the same
documents either way.

`Serenade.GIF.rar` is the same program with `NOTICE.txt`, `EULA.txt`,
`Guide.txt` and the `licenses` folder already unpacked next to it. Take
this one if you have the author's permission to pass the program on,
because those files have to travel with it. Passing on the program itself
needs that permission (see REDISTRIBUTION in the EULA); the open-source
components inside it carry their own, broader rights that no permission of
the author's can limit.

`ffmpeg-7.1.5.tar.xz` is source code, not something you need in order to
use the program. See below.

## Assets replaced 21 August 2026

The two downloads on this release were rebuilt and re-uploaded on that
date. The version number did not change, so the in-app updater will not
offer this to you: if you downloaded before 21 August, download again from
this page to get it. Nothing about what the program does has changed.

What changed is licence compliance and size. The build no longer bundles
Qt, which was present but unused and unattributed. The bundled FFmpeg was
rebuilt from source as a minimal GIF-only encoder, which removed more than
forty external libraries along with it. Attribution went from 11 licence
files to 33, several of which were missing outright, and the FFmpeg
components were relabelled after the rebuild changed which version of the
LGPL applies to them. The EULA now grants the modification and
reverse-engineering permission that the LGPL requires of it, which the
first build did not. The download dropped from 98 MB to 54 MB as a side
effect.

## Open-source components

Serenade GIF's own code is closed, but it is built on open-source software
and ships a good deal of it inside the executable: Python, Pillow, OpenCV,
NumPy, Tcl/Tk, FFmpeg and others. Every one is named, attributed and
licensed in `NOTICE.txt`, with full licence texts in the `licenses` folder.
Both come with the download, and the program has a **Licences** button in
its toolbar that shows all of them without leaving the app.

**FFmpeg source.** The bundled `ffmpeg.exe` is covered by the GNU Lesser
General Public License version 2.1. Its FFmpeg source is the unmodified
official FFmpeg 7.1.5 release, attached to this release as
`ffmpeg-7.1.5.tar.xz`, so the source is available from the same place as
the binary. It is byte-for-byte the upstream tarball from
https://ffmpeg.org/releases/ and `ffmpeg-7.1.5.tar.xz.asc` is upstream's
own signature for it. Nothing in it is patched or added. The binary will
print the configure line used to build it if you run `ffmpeg.exe -version`.
Being a static build it also has zlib 1.3.1 and the mingw-w64 and GCC
runtimes compiled into it, which are not part of that tarball. `NOTICE.txt`
names them, and the written offer below covers their source too.

`NOTICE.txt` carries a written offer, good for three years, covering both
that binary and the FFmpeg libraries inside OpenCV's video decoder.
Requests go through [Issues](https://github.com/LunarSerenade/serenade-gif/issues).

The EULA permits you to modify your own copy for your own use, to reverse
engineer it as far as needed to debug those modifications, and to extract
any bundled third-party component out of the executable and redistribute it
under its own licence.
